1 Tentang Aplikasi

Gambaran umum Evently dan masalah yang diselesaikannya.

Evently adalah aplikasi mobile untuk pendaftaran dan manajemen event. Aplikasi ini menghubungkan dua peran sekaligus:

  • Peserta — menjelajah event, mendaftar, menerima tiket + QR code, dan menerima notifikasi.
  • Admin — mengelola kategori, membuat/mengedit event, dan menyetujui atau menolak pendaftaran peserta.

Aplikasi terdiri dari aplikasi mobile (Flutter) yang berkomunikasi dengan API (Laravel) melalui protokol HTTP/JSON menggunakan autentikasi token Sanctum. Semua antarmuka, pesan, dan status menggunakan bahasa Indonesia.

Alur inti: peserta mendaftar event → status Menunggu → admin Menerima/Menolak → peserta dapat notifikasi → jika diterima, tiket + QR code dibuat otomatis.

3 Fitur Lengkap Aplikasi

Penjelasan menyeluruh setiap fitur yang sudah diimplementasikan.

Registrasi & Login

Pendaftaran akun baru (nama, email, no. HP, password min. 8 karakter + konfirmasi) dan login dengan email & password. Sesi disimpan otomatis sehingga tidak perlu login ulang.

Prioritas tinggi

Profil & Logout

Lihat dan ubah nama lengkap serta nomor HP, badge peran (Admin/Peserta), dan keluar dari aplikasi dengan konfirmasi. Admin juga bisa mengakses halaman profil dari dashboardnya.

Autentikasi

Splash & Role Router

Saat aplikasi dibuka, splash screen memeriksa sesi tersimpan lalu otomatis mengarahkan ke halaman yang tepat: Admin → Dashboard Admin, Peserta → Beranda, belum login → Login.

Navigasi

Pencarian Event

Kotak pencarian pada beranda memfilter event berdasarkan judul, lokasi, atau penyelenggara secara real-time setiap kali teks berubah.

Beranda

Filter Kategori

Choice chip horizontal berisi kategori event (Semua, Seminar, Workshop, Webinar, Lomba, Pelatihan). Ketuk satu kategori untuk menyaring daftar event.

Beranda

Daftar & Detail Event

Daftar event dengan kartu bergambar + infinite scroll (paginasi) dan tarik-untuk-refresh. Halaman detail menampilkan gambar, badge status, kategori, tanggal (format Indonesia), waktu, lokasi, penyelenggara, kuota terdaftar, dan deskripsi.

Prioritas tinggi

Pendaftaran Event

Tombol Daftar Sekarang dengan dialog konfirmasi. Validasi: event harus berstatus Aktif, kuota belum penuh, dan belum pernah mendaftar (mencegah duplikat).

Prioritas tinggi

Status Pendaftaran

Tab Pendaftaran menampilkan semua pendaftaran dengan badge status Menunggu, Diterima, atau Ditolak, lokasi event, dan kode tiket bila sudah diterima.

Peserta

Tiket + QR Code

Tiket dibuat otomatis saat pendaftaran diterima. Tab Tiket Saya menampilkan kartu tiket gradasi navy berisi QR code dan kode tiket unik (contoh EVT-…) untuk check-in.

Prioritas tinggi

Notifikasi In-App

Notifikasi otomatis dikirim saat pendaftaran diterima/ditolak. Terdapat badge jumlah belum dibaca, dialog pop-up saat membuka beranda, tanda baca/belum baca, dan detail notifikasi.

Peserta

Riwayat Pendaftaran

Menu Riwayat (ikon jam) menampilkan seluruh riwayat pendaftaran dengan status dan kode tiket, serta tombol Hapus dengan dialog konfirmasi.

Peserta

Dashboard Admin

Kartu selamat datang + menu utama: Kelola Event, Kelola Kategori, Kelola Pendaftaran, dan Profil. Admin juga bisa mengakses kelola pendaftaran lewat ikon riwayat.

Admin

CRUD Event (Admin)

Tambah, edit, dan hapus event. Form lengkap: judul, kategori (dropdown), deskripsi, penyelenggara, lokasi, tanggal (date picker), waktu mulai/selesai, kuota, status, dan pemilihan tema gambar.

Prioritas tinggi

CRUD Kategori (Admin)

Kelola kategori lewat dialog: tambah, edit nama + deskripsi, dan hapus. Ada tombol FAB Tambah Kategori dan ikon edit/hapus pada tiap baris kategori.

Admin

Verifikasi Pendaftaran (Admin)

Daftar pendaftaran dengan nama & email peserta serta tanggal daftar. Tombol Terima / Tolak untuk pendaftaran berstatus Menunggu, plus hapus riwayat.

Prioritas tinggi

Auto: Tiket & Notifikasi

Logika bisnis otomatis di backend: saat admin menerima pendaftaran, sistem membuat tiket + QR code dan notifikasi ke peserta; saat ditolak, hanya notifikasi.

Backend

Tema Gambar Event

8 tema gambar gradasi (Navy, Gold, Teal, Royal, Maroon, Forest, Sunset, Ocean) dipilih lewat grid saat membuat event. Gambar tampil di kartu dan detail event.

Ilustrasi

Validasi & Keamanan

Validasi password (min. 8 karakter), format email, kuota (0 = tanpa batas), dan proteksi role: hanya admin yang boleh mengubah event/kategori/status pendaftaran (403 bila bukan admin).

Keamanan
Status event: Aktif (bisa didaftar) · Selesai · Ditutup (tidak menerima pendaftaran). Non-admin hanya melihat event Aktif.

8 Struktur Database

6 tabel utama di database MySQL evently beserta relasinya.

TabelKolom utamaRelasi
usersname, email (unique), password, phone, role admin / user—
categoriescategory_name, description—
eventscategory_id, title, description, organizer, location, event_date, start_time, end_time, quota, image, status Aktif/Selesai/Ditutupcategory_id → categories.id
registrationsuser_id, event_id, registration_date, status Menunggu/Diterima/Ditolakuser_id → users.id, event_id → events.id
ticketsregistration_id, ticket_code (unique), qr_coderegistration_id → registrations.id
notificationsuser_id, title, message, is_read (boolean)user_id → users.id
Catatan penting: tabel registrations memiliki constraint UNIQUE(user_id, event_id) sehingga peserta tidak bisa mendaftar ganda pada event yang sama. Nilai quota = 0 berarti kuota tanpa batas. Semua foreign key memakai CASCADE.

9 Menjalankan Aplikasi

Langkah menjalankan Evently secara lengkap.

1) Jalankan MySQL

"D:\laragon\bin\mysql\mysql-8.4.3-winx64\bin\mysqld.exe"

2) Jalankan Backend Laravel

cd backend
composer install
php artisan serve --port=8000

Verifikasi & isi data awal:

php artisan migrate:fresh --seed   # 5 kategori + akun admin

3) Jalankan Aplikasi Flutter

cd mobile
flutter pub get
flutter run -d windows   # atau -d chrome / emulator Android
Android emulator memakai base URL 10.0.2.2:8000 (alamat ke komputer host), sedangkan web/Windows memakai 127.0.0.1:8000. Config ada di lib/config/api_config.dart.
